TikTok FYP research pilot

Pilot settings

These values become a locked snapshot when a new collection session starts. Editing them never changes a session already in progress.

seconds
The collector keeps every safely confirmed recommendation it can source during this wall-clock window. It opens the viewer when time ends, provided at least one video was collected. Hidden-tab throttling still counts.
qualified seconds
Used only by the separate natural-browsing Qualtrics survey. Time counts while its TikTok tab is visible and focused and one identifiable, substantially visible video is actively playing.

Pilot data boundary

Both participant-facing modes start from their own allowlisted Stanford Qualtrics survey. The natural mode records numeric post IDs, qualified exposure duration, and bounded event counts; it never records key values, cursor coordinates, usernames, captions, or creator information. This prototype has no general upload endpoint, participant identifier, or oTree integration.
